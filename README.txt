KHOEN Super App — Web/PWA Prototype

To preview: open index.html in a browser.
To install as an app: host this folder on an HTTPS website, open it in Chrome on Android, then choose Install app / Add to Home screen. Service worker offline caching requires HTTPS (or localhost).

Included demo sections:
- KHOEN Home and service dashboard
- KHOEN Store (sample app catalogue and search)
- KHOEN Trade (illustrative portfolio and fictional market examples)
- KHOEN Wallet (non-functional demo)
- KHOEN Chat placeholder and KHOEN ID profile

This is a front-end prototype only. It has no real login, backend, chat, AI, app downloads, payments, bank account opening, cards, deposits, withdrawals, brokerage, exchange, or live market data. Do not use demo values for financial decisions. Real financial features require licensed partners, security controls, compliance and country-specific regulatory approvals.
